How do I install Puff?

Download the APK and transfer it to your Android TV. Allow installation from your chosen file manager, then open the APK. Read the setup guide for cleanup authorization and Home controls. Casting can be started separately.

Will it make every TV faster?

Results depend on the hardware and apps. Puff can stop selected background apps; it cannot add RAM or repair slow hardware. It has been tested on an older OnePlus Android 11 TV. This is beta software.

What permissions does it need?

Cleanup requires local ADB authorization. The optional Home companion uses accessibility to identify the foreground app and your chosen remote shortcut. Casting uses your local network. Enable only the features you want.

FROM DOWNLOAD TO BIG SCREEN

Bring Puff home.

Use your Mac, Windows PC or Linux computer to install Puff on your Android TV.

Puff runs on Android TV. Puff Installer is the separate desktop helper that puts it there. Android 9 or newer is required.

RECOMMENDED / NO TERMINAL COMMANDS

Meet Puff Installer.

A small desktop helper that finds compatible TVs on your network, checks the device, and installs Puff for you. Enable network debugging on the TV and approve its connection prompt; the installer handles the commands.

Mac · Apple siliconMac · IntelWindows · x64

Installer beta 0.1 · macOS 13+ / Windows 10+ · Internet required for downloads. No publisher signature; macOS build is not notarized. Windows build is not yet tested on a Windows PC.

  1. Open the helper. On Mac, unzip and move Puff Installer to Applications. On Windows, extract the whole ZIP and open Puff Installer.exe inside it.
  2. Prepare once. Read and accept Google’s Android SDK license if you agree. The helper downloads the official Android tools directly from Google.
  3. Find your TV. Enable its supported network debugging option and choose Find my TV. Select the TV and approve its debugging prompt. A manual address option and wireless pairing-code form are available.
  4. Install. Confirm the TV model, then choose Install Puff on this TV. The APK is checked before installation, and compatible existing installations retain their settings.

Discovery depends on your TV’s debugging support and network settings. The helper cannot enable TV debugging or approve TV prompts for you. If your TV does not support network debugging, use the USB-drive option below. Installer source and details.

OPTION 01 / USB DRIVE

The simple way.

  1. Download Puff.apk on your computer.
  2. Copy the APK to a USB drive your TV supports, then plug it into the TV.
  3. Use a file manager on the TV to open the APK. If prompted, allow that file manager to install unknown apps.
  4. Select Install, then open Puff from your TV’s apps list. You can turn the file manager’s install permission off afterward.

No debugging needed for this installation method. Cleanup has its own optional setup below.

OPTION 02 / LOCAL NETWORK

Install with ADB.

  1. Download Puff.apk and Google’s SDK Platform Tools for your computer. Extract the tools and put the APK inside the platform-tools folder.
  2. On the TV, enable Developer options (usually Settings, About, then select Build seven times). Enable its supported network debugging option. Connect the TV and computer to the same trusted network.
  3. Find the TV’s IP address in its network settings. Use the connection method below that your TV offers.

USB debugging alone does not enable network ADB on every TV. If no supported network option is available, use the USB-drive method.

Open a terminal in platform-tools.

On macOS or Linux, open Terminal and use cd followed by the folder’s path. On Windows, open PowerShell in that folder. Replace the placeholders below with the addresses and ports shown by your TV; do not paste the placeholder names literally.

macOS / Linux commands

For a TV with legacy network ADB on port 5555:

./adb connect TV_IP:5555
./adb devices
./adb -s TV_IP:5555 install -r Puff.apk

Approve the debugging request on your TV after connecting. Continue only when adb devices shows device, not unauthorized.

Windows PowerShell commands
.\adb.exe connect TV_IP:5555
.\adb.exe devices
.\adb.exe -s TV_IP:5555 install -r Puff.apk

Approve the TV’s debugging prompt after connecting, then verify the device is authorized before installing.

My TV shows Wireless debugging with a pairing code

Choose “Pair device with pairing code” on the TV. Pair using that screen’s address and pairing port, then connect with the connection port on the main Wireless debugging screen. These ports can differ.

./adb pair TV_IP:PAIRING_PORT
./adb connect TV_IP:CONNECTION_PORT
./adb devices
./adb -s TV_IP:CONNECTION_PORT install -r Puff.apk

Enter the pairing code when prompted. In Windows PowerShell, replace ./adb with .\adb.exe. This installs Puff, but Puff’s automatic cleanup does not currently support this newer pairing flow.

Connection or installation not working?

Connection refused: confirm the TV’s supported debugging mode, IP and port. Unauthorized: accept the request on the TV. Not found: check that Puff.apk is inside platform-tools. Signature mismatch: use an update signed by the same publisher; uninstalling an existing app removes its saved data. Consult Google’s ADB guide for device-specific connection troubleshooting.

ONE LAST THING

Choose what Puff does.

  1. For casting: open Puff, choose Cast, then Start. Keep your phone and TV on the same trusted network.
  2. For the floating cloud: enable Puff Home controls in Accessibility. The current Home overlay supports Google’s Android TV launcher. Pick an optional remote shortcut in Puff.
  3. For automatic cleanup: your TV must support local ADB at 127.0.0.1:5555. Choose Authorize this TV in Puff, approve Puff’s own debugging prompt, then enable cleanup after restart. Authorizing your computer does not authorize Puff.

Once configured, the TV runs Puff without your computer. Keep the TV’s supported local debugging enabled if using cleanup. For casting alone, debugging can be turned off after installation. Read the full setup and compatibility notes.

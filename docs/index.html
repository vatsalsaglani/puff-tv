How do I install Puff?

Download the APK and transfer it to your Android TV. Allow installation from your chosen file manager, then open the APK. Read the setup guide for cleanup authorization and Home controls. Casting can be started separately.

Will it make every TV faster?

Results depend on the hardware and apps. Puff can stop selected background apps; it cannot add RAM or repair slow hardware. It has been tested on an older OnePlus Android 11 TV. This is beta software.

What permissions does it need?

Cleanup requires local ADB authorization. The optional Home companion uses accessibility to identify the foreground app and your chosen remote shortcut. Casting uses your local network. Enable only the features you want.

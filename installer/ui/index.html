A small toolkit. A simple setup.

Puff uses Google’s Android tools behind the scenes. We’ll download them directly from Google once. You won’t need to run any commands.

Turn on your TV.

Connect this computer and your Android TV to the same trusted Wi-Fi or wired network. In the TV’s Developer options, enable network or wireless debugging.

Where are Developer options?

Usually: Settings, Device Preferences or System, About. Select Build seven times, then go back to Developer options. TV menus differ. USB debugging alone may not enable network access; if your TV has no network option, use the USB-drive guide in Help.

TV not found? Enter its address

Find the IP in your TV’s network settings. Use the debugging port it shows; older network-debugging TVs usually use 5555.

My TV shows a pairing code

Choose “Pair device with pairing code” on your TV. Enter its pairing address and six-digit code here. After pairing, connect with the address on the main Wireless debugging screen; its port may be different.

CONNECTED TO YOUR TV

Install Puff 3.0 beta 4. If Puff is already installed with the same signature, this updates it and keeps its settings.

A little more room.

In Puff, choose Cast then Start to share your screen. The floating cloud and automatic cleanup are optional: enable them on your TV using the setup guide.
